# Python Calculator

A simple command-line calculator built in Python. Supports basic arithmetic operations and keeps a history of calculations during the session.

## Features

- Addition, subtraction, multiplication, and division
- Input validation with clear error messages
- Handles division by zero
- Displays a history of all calculations at the end of the session
